# Advanced C# Lab Projects

## Hordhac

README-kan wuxuu soo bandhigayaa afar mashruuc oo lagu baranayo samaynta barnaamijyada C# Windows Forms. Mashruuc kasta wuxuu diiradda saarayaa gelinta xogta, hubinta saxnaanta xogta, xisaabinta kharashaadka iyo soo bandhigista natiijooyinka.

## 1. Hotel Room Booking

### Sharaxaad
Mashruucan waxaa loo isticmaalaa in lagu maamulo booking-ka qolalka hoteelka. User-ku wuxuu gelinayaa xogta martida, dooranayaa nooca qolka iyo adeegyada uu u baahan yahay.

### Waxyaabaha uu qabanayo
- Qaadashada magaca martida iyo da'da.
- Doorashada nooca qolka.
- Gelinta tirada habeenada iyo martida.
- Xisaabinta qiimaha qolka iyo quraacda.
- Ku dabaqidda discount-ka ku habboon.
- Hubinta in booking-ku buuxiyey shuruudaha.

### Badhamada
- **Calculate:** Wuxuu xisaabiyaa kharashka booking-ka.
- **Clear:** Wuxuu tirtiraa xogta la geliyey.
- **Exit:** Wuxuu xiraa application-ka.

### C# Concepts
Variables, data types, `TryParse()`, `if-else`, `switch`, logical operators iyo `bool bookingApproved`.

---

## 2. Passenger Ticket Booking

### Sharaxaad
Mashruucan wuxuu fududaynayaa xisaabinta tigidhada safarka. Waxaa lagu hubinayaa da'da rakaabka, tirada tigidhada, miisaanka boorsooyinka iyo nooca tigidhka.

### Waxyaabaha uu qabanayo
- Gelinta da'da rakaabka.
- Doorashada ticket class-ka.
- Gelinta tirada tigidhada iyo ticket price-ka.
- Hubinta xaddidaadaha boorsooyinka.
- Xisaabinta qiimaha tigidhada, discount-ka iyo insurance-ka.
- Muujinta sababta booking loo diiday haddii shuruudaha la buuxin waayo.

### Badhamada
- **Book/Calculate:** Wuxuu hubiyaa xogta kadibna xisaabiyaa lacagta.
- **Clear:** Wuxuu nadiifiyaa xogta.
- **Exit:** Wuxuu ka baxaa barnaamijka.

### C# Concepts
`int`, `double`, `string`, `bool`, `TryParse()`, conditional statements iyo currency formatting.

---

## 3. Vehicle Rental

### Sharaxaad
Mashruucan waxaa loogu talagalay in lagu xisaabiyo kharashka kirada gaadhiga iyadoo la eegayo nooca gaadhiga, muddada kirada iyo adeegyada dheeraadka ah.

### Waxyaabaha uu qabanayo
- Qaadashada xogta macmiilka.
- Hubinta da'da iyo khibradda wadista.
- Doorashada Economy, SUV ama Luxury.
- Xisaabinta kirada maalmaha.
- Ku darista insurance-ka haddii la doorto.
- Xisaabinta discount-ka iyo young driver surcharge-ka.
- Muujinta xaaladda kirada.

### Badhamada
- **Calculate:** Wuxuu hubiyaa u-qalmitaanka macmiilka, kadibna xisaabiyaa kirada.
- **Clear:** Wuxuu nadiifiyaa xogta iyo doorashooyinka.
- **Exit:** Wuxuu xiraa barnaamijka.

### C# Concepts
Variables, `TryParse()`, `if-else`, `switch`, RadioButtons, CheckBoxes iyo event handlers.

---

## 4. Course Registration

### Sharaxaad
Mashruucan wuxuu maamulaa diiwaangelinta ardayda iyo xisaabinta lacagaha waxbarashada. Qiimaha koorsooyinku wuxuu ku xiran yahay heerka waxbarasho ee ardayga.

### Waxyaabaha uu qabanayo
- Gelinta magaca ardayga iyo Student ID.
- Doorashada heerka waxbarashada.
- Gelinta tirada koorsooyinka.
- Xisaabinta tuition fee-ga.
- Ku darista hoyga iyo gaadiidka haddii la doorto.
- Xisaabinta discount-yada.
- Soo bandhigista lacagta ugu dambaysa.

### Badhamada
- **Register/Calculate:** Wuxuu hubiyaa xogta ardayga, kadibna xisaabiyaa lacagta diiwaangelinta.
- **Clear:** Wuxuu tirtiraa xogta iyo natiijada.
- **Exit:** Wuxuu xirayaa application-ka.

### C# Concepts
Variables, data types, `TryParse()`, `switch`, `if-else`, CheckBoxes, ComboBox iyo currency formatting.

---

## 5. Waxyaabaha Laga Baranayo

Afartan mashruuc waxay caawinayaan fahamka aasaaska C# iyo sida loo dhiso Windows Forms applications.

- **Variables:** Kaydinta xogta barnaamijka.
- **Data Types:** Kala saaridda qoraalka, tirooyinka iyo xaaladaha runta ama beenta.
- **Input Validation:** Hubinta in xogta user-ku geliyo ay sax tahay.
- **Conditional Statements:** Go'aan ka gaarista shuruudaha kala duwan.
- **Calculations:** Xisaabinta lacagaha iyo discount-yada.
- **Event Handlers:** Ka jawaabista marka badhamada la taabto.
- **Formatting:** Soo bandhigista lacagta qaab akhris fudud leh.
- **Boolean Variables:** La socodka xaaladda booking-ka ama diiwaangelinta.

## Gunaanad

Mashruucyadani waxay siinayaan ardayga fursad uu ku tababarto qorista code-ka C#, samaynta Windows Forms interfaces iyo xalinta dhibaatooyinka la xiriira xisaabinta iyo hubinta xogta. Mashruuc kasta wuxuu adeegsadaa fikradaha barnaamij-samaynta si loo abuuro application shaqaynaya oo sahlan in la isticmaalo.
